==============================
fxbLoader Readme:
==============================

The fxbLoader allows to load vst preset banks within the  
V-Machine and the VFX host software that do not offer this 
functionality.
The latest release of the program can be downloaded from 
http://soundbytes.de/?fxbLoader

 2. Installation:
-----------------

    Copy the folder fxbLoader from the supplied zip archive 
    anywhere onto your computers hard disk drive.
    Make sure to keep the directory structure intact.
	
	System requirements:
	OS: windows XP, Vista, windows 7
	VFX: version 2

	Note:
	If you use the program on a Vista or winXP system 
	You might need to install the Microsoft Visual 
	C++ 2010 Redistributable Package (x86)
	which is available from :
	http://www.microsoft.com/en-us/download/details.aspx?id=5555

 3. Deinstallation:
-------------------
   
    Delete the 'fxbLoader' folder from your computers storage media.
    Make sure to remove any unwanted instances of the fxbLoader from 
    your vfxLibraries before removing the configuration tool.

 4. How to use:
---------------

The Software consists of two different modules:

1) fxbLoaderConfig.exe
This configuration utility is used to add or remove the fxbLoader to 
or from any plugin in a chosen VFX-Library.
2) fxbLoader.dll
Once the fxbLoader has been added to a plugin it will load a preselected 
fxb preset bank into the plugin as soon as the plugin is opened in the
V-Machine or the VFX VST host software.
A dialog is available that allows to import fxb preset banks and to select 
the fxb bank to be loaded on startup 

fxbLoader configuration:

 1. Start fxbLoaderConfig.exe 
 2. Hit the button 'open vfxLibrary' and select the folder you want to 
    modify. 
    Note: The library needs to contain at least one vst plugin. 
    Make sure that all the plugins are properly configured to run on the
    V-Machine.
 3. All vst plugins in the library will appear in one of the two 
    list boxes. The left box shows all plugins that do not yet have 
    the fxbLoader installed while the right box shows those plugins
    where the fxbLoader has already been added.
 4. Add the fxbLoader by selecting one or more entries from the 
    listbox to the left. Then hit the '>>' button. The selected 
    plugin directories are modified accordingly and will then be  
    shown in the 'enabled' listbox to the right. 
    NOTE: the fxbLoader configuration tool saves the original
    vfxinfo.txt as vfxinfo.tx_. Do _not_ delete this file. 
    Otherwise you will have to manually edit the modified 
    vfxinfo.txt in order to restore the original state of the plugin 
	if you should decide to remove the fxbLoader from the plugin.
 5. To remove the fxbLoader select one or more entries from the 
    listbox to the right then hit the '<<' button. The selected 
    plugins will now be restored to their original state.
 6. Always close and restart the VFX host after any changes have been 
    made to the fxbLoader configuration of the hosted plugins.  
 
fxbLoader:

 1. The fxbLoader dialog appears whenever the VST plugin panel is 
	opened. Mouse click the VFX icon in the top left corner 
	of the VFX program window and select 'Show VST Editor'.
	If the Plugin Panel is already visible you will have to close the 
	panel first before you can open it. 
 2. Initially there are no fxb bank files available. 
    Click the 'import new fxb bank file' Button and select one or more 
    appropriate banks using the file open dialog that appears. The fxb 
    bank file will be copied to the plugin directory and is from 
    then on readily available from the listbox.
    NOTE: 
	A previosly imported fxb bank will be overwritten without 
    warning when a new bank with the same file name is imported.
	The utility checks the fxb-Bank for compatability and will not 
	add any banks that were created with another plugin.
 3. Any banks that have been imported previously are shown in the 
    listbox and can be selected from there.
 4. If no bank is to be loaded check the 'load none' radio button. 
    This will also disable the listbox.
 5. When all settings are completed hit the ok button. 
    The configured fxb bank will now be loaded into the VST plugin.

 5. Known issues and limitations:
---------------------------------

fxbLoaderConfig.exe:
The VFX host might crash when a plugin is reloaded that has been 
equipped with the fxbLoader during the same VFX host session. 
This is no bug but instead an interoperability problem that can not 
be fixed currently.
Workaround: 
Always close and restart the VFX host application after 
fxbLoaderConfig.exe was used to modify the vfxLibrary currently
loaded in the VFX host.

fxbLoader:
Once a fxb preset bank has been loaded into the plugin the 
fxbLoader can not be used to restore the factory default bank.
Workaround:
To restore the factory default bank:
Open the fxbLoader dialog and chack the 'load none' radio button.
Hit the ok button.
Unload the plugin and reload it into the VFX application. 

The fxbLoader can only be used to load fxb preset banks. Saving of fxb 
preset banks is not possible with the software.
Workaround:
Use any other VST host to edit and save fxb preset banks.

fxbLoader removal:
Any imported fxb bank file will be kept in place together with 
the fxbLoader.dll. A backup of the modified vfxinfo.txt is kept under 
the name vfxinfo.loader. These files need to be removed manually.
